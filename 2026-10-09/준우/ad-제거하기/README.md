# ad 제거하기

## 문제 설명

문자열 배열 `strArr`이 주어집니다.

배열의 각 문자열 중 `"ad"`라는 부분 문자열을 포함하는 문자열을 제거하고, 남은 문자열을 순서대로 담은 배열을 반환하는 문제입니다.

## 입출력 예시

| strArr | result |
|---|---|
| `["and", "notad", "abcd"]` | `["and", "abcd"]` |
| `["there", "are", "no", "a", "ds"]` | `["there", "are", "no", "a", "ds"]` |

## 풀이 방법

1. `strstr()` 함수를 이용하여 각 문자열에 `"ad"`가 포함되어 있는지 확인합니다.
2. `for`문을 사용하여 `"ad"`가 포함된 문자열의 개수를 `cnt`에 저장합니다.
3. 전체 배열 길이에서 `cnt`를 빼서 결과 배열의 크기를 계산합니다.
4. `malloc()`으로 결과 문자열 배열을 동적 할당합니다.
5. `while`문을 사용하여 원본 배열을 순회합니다.
6. `"ad"`가 포함되지 않은 문자열만 `malloc()`과 `strcpy()`를 이용하여 결과 배열에 복사합니다.
7. 완성된 배열을 반환합니다.

## 사용한 주요 함수

- `strstr()` : 문자열에 특정 부분 문자열이 존재하는지 확인
- `strlen()` : 문자열의 길이 계산
- `malloc()` : 필요한 메모리 동적 할당
- `strcpy()` : 문자열 복사

## 핵심 코드

```c
if (strstr(strArr[k], "ad") == NULL) {
    int num2 = strlen(strArr[k]);
    answer[j] = (char*)malloc(sizeof(char) * (num2 + 1));
    strcpy(answer[j], strArr[k]);
    j++;
}
k++;
```

## 배운 점

- `strstr()`은 찾는 문자열이 없으면 `NULL`을 반환합니다.
- `char**` 자료형을 사용하여 문자열 배열을 처리할 수 있습니다.
- 문자열 배열을 동적 할당할 때는 포인터 배열과 각 문자열의 메모리를 각각 할당해야 합니다.
- 문자열을 복사할 때는 널 문자(`'\0'`)를 위한 공간을 추가해야 합니다.
- 원본 배열의 인덱스와 결과 배열의 인덱스를 따로 관리하면 필요한 문자열만 저장할 수 있습니다.
