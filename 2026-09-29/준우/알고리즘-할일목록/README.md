# 할 일 목록

## 문제 설명
오늘 해야 할 일이 담긴 문자열 배열 `todo_list`와 각각의 일을 지금 마쳤는지를 나타내는 boolean 배열 `finished`가 주어질 때, 아직 마치지 못한 일들을 순서대로 담은 문자열 배열을 반환하는 문제.

## 풀이
1. `finished` 배열을 순회하면서 `false`인 원소의 개수를 구한다.
2. 구한 개수만큼 `answer`의 포인터 배열을 동적 할당한다.
3. 다시 `finished`를 순회하면서 `false`인 경우 해당 문자열의 길이만큼 메모리를 동적 할당한다.
4. `strcpy()`를 사용해 `todo_list[i]`를 `answer`에 복사한다.
5. 완성된 `answer`를 반환한다.

## 배운 점
- `bool` 배열은 `!finished[i]`를 이용해 `false`인지 간단하게 확인할 수 있다.
- `char**` 문자열 배열은 포인터 배열을 먼저 동적 할당한 뒤, 각 문자열을 저장할 공간도 각각 동적 할당해야 한다.
- `strlen()`을 사용할 때 문자열의 마지막 `\0` 공간을 위해 `+1`만큼 할당해야 한다.
- `strcpy()`를 사용하면 문자열을 다른 메모리 공간으로 복사할 수 있다.
