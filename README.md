# 코딩테스트 스터디

매일 문제를 풀고 풀이 내용을 GitHub에 기록하는 스터디입니다.

## 매일 풀 문제

| 참여자 | 문제 |
| --- | --- |
| 조해민 | SQL 1문제, 프로그래머스 알고리즘 고득점 Kit 1문제 |
| 서준우 | 프로그래머스 알고리즘 1문제 |

## 업로드 규칙

- 매일 자정(24:00)까지 GitHub에 풀이를 업로드합니다.
- 각 문제의 **문제 설명**과 **풀이 코드**를 함께 올립니다.
- 기한 내 업로드하지 않으면 **5,000원**을 냅니다.

## 폴더 구성

날짜별 폴더 안에 각자의 이름으로 폴더를 만들고, 문제마다 별도 폴더를 사용합니다.

```text
CodingTest/
├── README.md
└── YYYY-MM-DD/
    ├── 조해민/
    │   ├── SQL-문제번호/
    │   │   ├── README.md
    │   │   └── solution.sql
    │   └── 알고리즘-문제번호/
    │       ├── README.md
    │       └── solution.py
    └── 서준우/
        └── 알고리즘-문제번호/
            ├── README.md
            └── solution.py
```

- `YYYY-MM-DD`는 풀이를 업로드하는 날짜로 바꿉니다.
- 각 문제의 `README.md`에는 문제 이름, 문제 링크, 문제 설명과 풀이 설명을 적습니다.
- `solution.sql`, `solution.py`에는 제출한 풀이 코드를 넣습니다. 사용한 언어에 맞게 파일 확장자를 바꿔도 됩니다.
- 커밋 메시지 예시: `2026-09-22 조해민 문제 풀이`
