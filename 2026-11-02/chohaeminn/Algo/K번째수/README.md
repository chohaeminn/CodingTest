## 사용 자료구조

파이썬 기본 자료구조인 리스트(List)와 내장 정렬 함수

## 자료구조 선택 이유

이 문제의 핵심 연산은 '특정 구간 슬라이싱'과 '정렬'입니다. 파이썬의 리스트는 인덱스를 활용한 슬라이싱(`array[시작:끝]`)을 직관적으로 지원합니다. 또한 내장된 정렬 함수는 Timsort 알고리즘 기반으로 최적화되어 있어 O(N log N)의 속도로 빠르게 정렬을 수행합니다. 배열의 최대 길이가 100으로 매우 작으므로, 복잡한 자료구조 없이 기본 리스트를 활용하는 것이 구현 및 실행 속도 측면에서 가장 효율적입니다.

## 문제 해결 흐름

1. `commands` 배열에 담긴 `[i, j, k]` 형태의 명령을 순서대로 순회합니다.
2. 파이썬 리스트는 인덱스가 0부터 시작하므로, `i`번째부터 `j`번째까지 자르기 위해 슬라이싱 범위를 `[i-1 : j]`로 설정하여 배열을 자릅니다.
3. 잘라낸 부분 배열을 오름차순으로 정렬합니다.
4. 정렬된 배열에서 `k`번째 수를 찾기 위해 `k-1` 인덱스 값을 찾아 정답 배열에 추가합니다.

## 입출력 예시 및 처리 과정

- 입력 배열: `[1, 5, 2, 6, 3, 7, 4]`
- 입력 명령: `[[2, 5, 3], [4, 4, 1], [1, 7, 3]]`

1. 첫 번째 명령 [2, 5, 3]
   - 배열의 인덱스 1부터 5 직전까지 자름: `[5, 2, 6, 3]`
   - 오름차순 정렬: `[2, 3, 5, 6]`
   - 3번째(인덱스 2) 숫자 추출: `5`

2. 두 번째 명령 [4, 4, 1]
   - 배열의 인덱스 3부터 4 직전까지 자름: `[6]`
   - 오름차순 정렬: `[6]`
   - 1번째(인덱스 0) 숫자 추출: `6`

3. 세 번째 명령 [1, 7, 3]
   - 배열의 인덱스 0부터 7 직전까지 자름: `[1, 5, 2, 6, 3, 7, 4]`
   - 오름차순 정렬: `[1, 2, 3, 4, 5, 6, 7]`
   - 3번째(인덱스 2) 숫자 추출: `3`

- 최종 반환값: `[5, 6, 3]`

## 전체 코드 및 주석

```python
def solution(array, commands):
    # 정답을 순서대로 담아 반환할 빈 리스트 생성
    answer = []

    # commands 배열 내의 [i, j, k] 묶음을 하나씩 순회
    for command in commands:
        # 언패킹을 통해 리스트의 3개 값을 각각 i, j, k 변수에 할당
        i, j, k = command

        # 1. 배열 자르기
        # 시작 인덱스는 0 기준에 맞춰 i-1로 지정하고, j번째 숫자까지 포함되게 슬라이싱
        sliced_array = array[i-1:j]

        # 2. 정렬하기
        # 잘라낸 리스트 자체를 오름차순으로 정렬
        sliced_array.sort()

        # 3. k번째 수 찾기
        # 인덱스 0부터 시작하므로 k번째 숫자는 k-1 인덱스에서 추출하여 정답 리스트에 추가
        answer.append(sliced_array[k-1])

    # 완성된 정답 리스트 반환
    return answer
```
