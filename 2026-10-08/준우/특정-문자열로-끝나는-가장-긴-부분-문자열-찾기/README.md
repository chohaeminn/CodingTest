# 특정 문자열로 끝나는 가장 긴 부분 문자열 찾기

## 문제 설명
문자열 `myString`과 `pat`이 주어질 때, `pat`으로 끝나는 가장 긴 부분 문자열을 반환한다.

## 풀이 방법
1. `strstr()`로 `pat`이 등장하는 위치를 찾는다.
2. `while`문으로 마지막 등장 위치를 찾는다.
3. `strlen(myString) - strlen(last) + strlen(pat)`으로 복사할 길이를 계산한다.
4. `malloc()`으로 메모리를 할당하고 `for`문으로 문자열을 복사한다.
5. 마지막에 널 문자 `\0`을 추가한다.
