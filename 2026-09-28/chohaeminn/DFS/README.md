# 네트워크

## 문제 설명

컴퓨터의 개수 `n`과 컴퓨터 간의 연결 정보를 담은 2차원 배열 `computers`가 주어질 때, 서로 연결된 네트워크의 개수를 구하는 문제이다.

직접 연결되어 있지 않더라도 다른 컴퓨터를 통해 이어져 있다면 같은 네트워크에 포함된다.

## 풀이 방법

모든 컴퓨터를 차례로 확인하면서 아직 방문하지 않은 컴퓨터를 발견하면 새로운 네트워크로 판단한다.

해당 컴퓨터부터 BFS를 시작하여 연결된 컴퓨터를 모두 방문 처리하고, BFS가 시작될 때마다 네트워크의 개수를 1씩 증가시킨다.

1. 컴퓨터의 방문 여부를 저장할 `visited` 배열을 만든다.
2. 방문하지 않은 컴퓨터를 발견하면 큐에 넣고 방문 처리한다.
3. 큐에서 컴퓨터를 하나씩 꺼내 연결된 컴퓨터 중 방문하지 않은 컴퓨터를 큐에 추가한다.
4. 연결된 모든 컴퓨터를 확인할 때까지 반복한다.
5. BFS를 시작한 횟수를 반환한다.

## 알게 된 점

서로 연결된 묶음의 개수는 BFS나 DFS를 시작한 횟수로 구할 수 있다는 것을 알게 되었다.

또한 2차원 배열로 주어진 연결 관계를 확인하면서 `visited` 배열을 사용하면 이미 탐색한 컴퓨터를 중복해서 방문하지 않을 수 있다.

## 복잡도

- 시간 복잡도: `O(n²)`
- 공간 복잡도: `O(n)`
