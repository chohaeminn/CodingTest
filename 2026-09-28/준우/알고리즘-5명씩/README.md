# 5명씩

## 문제 설명
최대 5명씩 탈 수 있는 놀이기구를 타기 위해 줄을 서 있는 사람들의 이름이 담긴 문자열 리스트 `names`가 주어질 때, 앞에서부터 5명씩 묶은 각 그룹의 가장 앞에 서 있는 사람의 이름을 담은 리스트를 반환한다.

마지막 그룹이 5명이 되지 않더라도 가장 앞에 있는 사람의 이름을 포함한다.

## 풀이 설명
먼저 `names_len`을 5로 나누어 필요한 그룹의 개수를 구했다.

`names_len`이 5로 나누어떨어지지 않는 경우 마지막 그룹이 하나 더 필요하므로 그룹의 개수에 1을 더했다.

계산한 그룹의 개수만큼 `char*`를 저장할 수 있도록 `answer` 배열을 동적 할당했다.

반복문을 사용하여 `names`를 처음부터 확인하고, 인덱스가 5의 배수인 경우 해당 이름을 `answer`에 저장했다.

`i / 5`를 이용하여 선택된 이름들이 `answer`의 0번 인덱스부터 순서대로 저장되도록 했다.
