# 🖥️ Programmers - 프로세스 (Python)

> 프로그래머스 스택/큐 문제인 **'프로세스'**의 파이썬 풀이 및 해설입니다.

---

## 📌 문제 설명

운영체제의 자원 관리 규칙에 따라 프로세스가 몇 번째로 실행되는지 알아내는 문제입니다.

### **실행 규칙**

1. 실행 대기 큐(Queue)에서 대기 중인 프로세스 하나를 꺼냅니다.
2. 큐에 대기 중인 프로세스 중 **우선순위가 더 높은 프로세스가 있다면** 방금 꺼낸 프로세스를 다시 큐에 넣습니다.
3. 만약 그런 프로세스가 없다면 방금 꺼낸 프로세스를 **실행**합니다. (한 번 실행한 프로세스는 다시 큐에 넣지 않고 종료)

---

## 💡 접근 방법 및 핵심 아이디어

1. **큐(Queue) 자료구조 활용**
   - 선입선출(FIFO) 특성을 가지며, 원소를 뒤로 보냈다가 꺼내는 시뮬레이션을 구현하기 위해 `collections.deque`를 사용했습니다. (`popleft()` 연산 시 시간 복잡도 `O(1)`)
2. **원래 위치(인덱스) 추적**
   - 큐가 회전하면서 순서가 바뀌더라도 원래 누구였는지 파악하기 위해, 초기 큐를 **`(우선순위, 원래 인덱스)`** 형태의 튜플로 구성했습니다.
3. **우선순위 비교 (`any()` 활용)**
   - 파이썬의 `any()` 함수와 제너레이터 표현식을 사용하여 대기 큐에 자신보다 우선순위가 높은 프로세스가 단 하나라도 존재하는지 효율적으로 검사했습니다.

---

## 💻 파이썬(Python) 코드 구현

```python
from collections import deque


def solution(priorities, location):
  # (우선순위, 원래 인덱스) 형태의 큐 생성
  queue = deque([(p, i) for i, p in enumerate(priorities)])
  answer = 0

  while queue:
    current = queue.popleft()

    # 큐에 남아있는 프로세스 중 우선순위가 더 높은 것이 있는지 확인
    if any(current[0] < q[0] for q in queue):
      queue.append(current)  # 우선순위가 높은 게 있다면 뒤로 보냄
    else:
      answer += 1  # 실행 완료 카운트 증가
      if current[1] == location:  # 찾고자 하는 프로세스라면
        return answer
```
