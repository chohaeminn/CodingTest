# 🛒 프로그래머스 - 재구매가 일어난 상품과 회원 리스트 구하기

---

## 📌 1. 문제 개요

- **출처:** 프로그래머스 SQL 코딩테스트 연습
- **테이블:** `ONLINE_SALE` (온라인 상품 판매 정보)
- **목적:** 동일한 회원이 **동일한 상품을 재구매한 데이터**를 추출하여 회원 ID와 상품 ID를 출력하기
- **정렬 조건:**
  1. 회원 ID 기준 **오름차순** 정렬
  2. 회원 ID가 같다면 상품 ID 기준 **내림차순** 정렬

---

## 💡 2. 접근 방법 및 해결 과정

이 문제는 동일한 회원과 상품 조합이 **2번 이상** 등장하는 데이터를 찾는 것입니다. 따라서 다음과 같은 단계로 SQL을 작성해야 합니다.

1. **그룹화 (`GROUP BY`)**: `USER_ID`와 `PRODUCT_ID`를 기준으로 그룹을 묶어줍니다.
2. **조건 지정 (`HAVING`)**: 그룹별 행의 개수를 세어(`COUNT(*)`) 2개 이상인 경우만 필터링합니다. (※ 집계 함수 조건이므로 `WHERE`가 아닌 `HAVING`을 사용해야 합니다.)
3. **정렬 (`ORDER BY`)**: 요구사항에 맞게 회원 ID는 오름차순, 상품 ID는 내림차순으로 정렬합니다.

---

## 💻 3. 정답 SQL 코드

```sql
SELECT USER_ID, PRODUCT_ID
FROM ONLINE_SALE
GROUP BY USER_ID, PRODUCT_ID
HAVING COUNT(*) >= 2
ORDER BY USER_ID ASC, PRODUCT_ID DESC;
```
