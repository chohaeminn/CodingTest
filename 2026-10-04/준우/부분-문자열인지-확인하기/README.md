# 부분 문자열인지 확인하기

## 문제 설명
부분 문자열이란 문자열에서 연속된 일부분에 해당하는 문자열을 의미합니다.

문자열 `myString`과 `pat`이 주어질 때, `myString`의 연속된 부분 문자열 중 `pat`과 같은 문자열이 존재하면 1을, 그렇지 않으면 0을 반환합니다.

단, 알파벳 대문자와 소문자는 구분하지 않습니다.

## 풀이 방법
1. `strlen()`을 이용해 `myString`과 `pat`의 길이를 구한다.
2. `pat`이 들어갈 수 있는 시작 위치를 `for`문으로 하나씩 확인한다.
3. 각 시작 위치에서 `pat`의 문자들을 차례대로 비교한다.
4. `tolower()`를 사용해 두 문자를 소문자로 변환한 뒤 비교한다.
5. 문자가 다르면 `cnt`를 0으로 초기화하고 해당 위치의 비교를 중단한다.
6. `cnt`가 `pat`의 길이와 같아지면 부분 문자열이 존재하므로 1을 반환한다.
7. 끝까지 일치하는 부분 문자열이 없다면 0을 반환한다.
