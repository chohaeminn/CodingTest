# 주식가격 문제 분석 및 해결 전략

## 1. 문제 개요

- **목표**: 초 단위로 기록된 주식 가격 배열 `prices`가 주어질 때, 각 가격이 떨어지지 않고 유지된 기간을 배열로 반환
- **제한사항**:
  - 각 가격: 1 이상 10,000 이하의 자연수
  - 배열 길이: 2 이상 100,000 이하

---

## 2. 왜 스택을 떠올려야 하는가? (어려웠던 점과 직관)

### 브루트포스(완전탐색)의 한계와 어려움

처음 이 문제를 마주하면 이중 반복문을 돌며 뒤쪽을 일일이 탐색해 가격이 떨어지는 시점을 찾으려 하기 쉽습니다.

- `prices`의 길이가 최대 **100,000**이므로, 단순 반복문 접근 시 **$O(N^2)$** 시간 복잡도가 발생합니다 ($100,000 \times 100,000 = 10,000,000,000$ 연산). 이는 어김없이 **시간 초과(TLE)**로 이어집니다.
- 이 문제의 가장 큰 어려움과 핵심은 **"미래의 모든 값을 일일이 확인하는 습관을 버리고, 아직 하락 시점을 모르는 과거의 데이터들을 효율적으로 보관(Deferred Calculation)할 방법이 무엇인가"**를 깨닫는 데 있습니다.

### 모노톤 스택(Monotonic Stack)을 떠올리는 순간

- 과거의 데이터와 현재 데이터를 중복 비교 없이 효율적으로 처리해야 할 때 스택을 활용합니다.
- 스택에 **아직 가격이 떨어지지 않은 인덱스**들을 오름차순으로 유지합니다.
- 현재 가격이 스택 맨 위의 가격보다 낮아지는 순간(하락 발생), 과거의 대기 중이던 인덱스들을 즉시 꺼내어 기간을 확정 짓습니다. 이 아이디어를 통해 $O(N^2)$ 문제를 **$O(N)$**으로 극복할 수 있습니다.

---

## 3. 파이썬 코드 구현

```python
def solution(prices):
    answer = [0] * len(prices)
    stack = []  # 아직 가격이 떨어지지 않은 인덱스들을 저장

    for i, price in enumerate(prices):
        # 현재 가격이 이전 가격보다 떨어졌다면, 스택에서 꺼내며 기간 계산
        while stack and prices[stack[-1]] > price:
            j = stack.pop()
            answer[j] = i - j  # (현재 인덱스) - (과거 인덱스)

        stack.append(i)

    # 끝까지 가격이 떨어지지 않은 원소들 처리
    while stack:
        j = stack.pop()
        answer[j] = len(prices) - 1 - j

    return answer
```
