# 🐾 동명 동물 수 찾기 (SQL)

## 📌 문제 설명

ANIMAL_INS 테이블은 동물 보호소에 들어온 동물의 정보를 담은 테이블입니다.
동물 보호소에 들어온 동물 이름 중 **두 번 이상 쓰인 이름과 해당 이름이 쓰인 횟수**를 조회하는 SQL문을 작성해주세요.

- **조건 1:** 이름이 없는 동물은 집계에서 제외합니다.
- **조건 2:** 결과는 이름 순으로 조회합니다.

---

## ❌ 첫 번째 시도 (실패)

작성한 초기 쿼리:

```sql
SELECT NAME, COUNT(*)
FROM ANIMAL_INS
GROUP BY NAME
HAVING COUNT(*) >= 2
ORDER BY NAME;
```
