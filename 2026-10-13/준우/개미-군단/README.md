# 개미 군단

## 문제 설명
개미 군단이 사냥을 나가려고 합니다.

개미 군단은 사냥감의 체력에 맞는 병력을 데리고 나가려고 합니다.

개미 군단의 개미는 각각 다음과 같은 공격력을 가지고 있습니다.

- 장군개미: 공격력 5
- 병정개미: 공격력 3
- 일개미: 공격력 1

사냥감의 체력 `hp`가 매개변수로 주어질 때, 사냥감의 체력을 감소시키기 위해 필요한 최소한의 개미 수를 반환하는 `solution` 함수를 완성하는 문제입니다.

## 제한사항
- 0 ≤ hp ≤ 1000

## 입출력 예

| hp | result |
|---|---|
| 23 | 5 |
| 24 | 6 |
| 999 | 201 |

## 문제 풀이

1. 사냥감의 체력 `hp`를 5로 나누어 장군개미의 수를 구합니다.
2. 장군개미가 공격한 만큼 체력을 감소시킵니다.
3. 남은 체력을 3으로 나누어 병정개미의 수를 구합니다.
4. 병정개미가 공격한 만큼 체력을 감소시킵니다.
5. 마지막으로 남은 체력만큼 일개미를 배치합니다.
6. 세 종류의 개미 수를 모두 더하여 반환합니다.


## 사용 개념
- 정수 나눗셈 (`/`)
- 산술 연산 및 복합 대입 연산자 (`-=`)
- 그리디 알고리즘 (Greedy Algorithm)

## 시간 복잡도
- **O(1)** : 입력값의 크기와 관계없이 일정한 횟수의 연산만 수행합니다.
