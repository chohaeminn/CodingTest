# 주사위의 개수

## 문제 설명

머쓱이는 직육면체 모양의 상자를 하나 가지고 있는데, 이 상자에 정육면체 모양의 주사위를 최대한 많이 채우고 싶습니다.

상자의 가로, 세로, 높이가 저장되어 있는 배열 `box`와 주사위 모서리의 길이 `n`이 매개변수로 주어질 때, 상자에 들어갈 수 있는 주사위의 최대 개수를 반환하는 문제입니다.

## 제한사항

- `box`의 길이는 3입니다.
- `box[0]` = 상자의 가로 길이
- `box[1]` = 상자의 세로 길이
- `box[2]` = 상자의 높이 길이
- 1 ≤ `box`의 원소 ≤ 100
- 1 ≤ `n` ≤ 50
- `n` ≤ `box`의 원소
- 주사위는 상자와 평행하게 넣습니다.

## 문제 풀이

1. 상자의 가로 길이 `box[0]`을 주사위의 모서리 길이 `n`으로 나누어 가로 방향에 들어갈 수 있는 주사위 개수를 구합니다.
2. 상자의 세로 길이 `box[1]`을 `n`으로 나누어 세로 방향에 들어갈 수 있는 주사위 개수를 구합니다.
3. 상자의 높이 `box[2]`를 `n`으로 나누어 높이 방향에 들어갈 수 있는 주사위 개수를 구합니다.
4. 세 방향의 주사위 개수를 모두 곱하여 최대 주사위 개수를 반환합니다.

## 사용 개념

- 배열 인덱싱
- 정수 나눗셈 (`/`)
- 곱셈 (`*`)

## 시간 복잡도

- **O(1)** : 입력 크기와 관계없이 일정한 횟수의 연산만 수행합니다.

## 사용 언어

- C
