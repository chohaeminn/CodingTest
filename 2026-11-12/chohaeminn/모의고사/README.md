## 📝 문제 요약

수포자 삼인방이 일정한 규칙으로 수학 문제를 찍을 때, 정답 배열 `answers`가 주어지면 가장 많은 문제를 맞힌 사람을 배열에 담아 반환하는 문제입니다. (동점자가 여러 명일 경우 오름차순 정렬)

- **1번 수포자:** `1, 2, 3, 4, 5` 반복 (주기: 5)
- **2번 수포자:** `2, 1, 2, 3, 2, 4, 2, 5` 반복 (주기: 8)
- **3번 수포자:** `3, 3, 1, 1, 2, 2, 4, 4, 5, 5` 반복 (주기: 10)

---

## 💡 풀이 전략

1. **나머지 연산(`%`)을 활용한 주기 처리:** 문제 수가 최대 10,000개이므로 찍기 패턴 리스트를 길게 늘리지 않고, `i % len(패턴)`을 이용해 인덱스가 패턴의 끝을 넘어가면 다시 처음부터 순회하도록 처리합니다.
2. **독립적인 조건문(`if`) 채점:** 한 문제에 대해 여러 명이 동시에 정답을 맞힐 수 있으므로 `elif`가 아닌 개별 `if`문으로 각각의 점수를 누적합니다.
3. **최고 득점자 추출:** `max(scores)`로 최댓값을 구한 뒤, `scores` 리스트를 0번 인덱스부터 순회하며 `i + 1`을 결과 리스트에 담아 자연스럽게 오름차순 정렬을 유지합니다.

---

## 💻 Python 코드

```python
def solution(answers):
    # 수포자별 반복 찍기 패턴
    p1 = [1, 2, 3, 4, 5]
    p2 = [2, 1, 2, 3, 2, 4, 2, 5]
    p3 = [3, 3, 1, 1, 2, 2, 4, 4, 5, 5]

    # 각 수포자의 맞힌 문제 수 (인덱스 0, 1, 2 -> 1번, 2번, 3번 수포자)
    scores = [0, 0, 0]

    # 정답과 찍기 패턴 비교
    for i, ans in enumerate(answers):
        if ans == p1[i % len(p1)]:
            scores[0] += 1
        if ans == p2[i % len(p2)]:
            scores[1] += 1
        if ans == p3[i % len(p3)]:
            scores[2] += 1

    # 가장 높은 점수 계산
    max_score = max(scores)

    # 최고 점수를 받은 사람(들)의 번호를 오름차순으로 반환
    result = []
    for i, score in enumerate(scores):
        if score == max_score:
            result.append(i + 1)

    return result
```
