# 길이에 따른 연산

## 문제 설명
정수가 담긴 리스트 `num_list`가 주어집니다.

리스트의 길이가 11 이상이면 리스트에 있는 모든 원소의 합을 반환하고,  
리스트의 길이가 10 이하이면 모든 원소의 곱을 반환합니다.

## 풀이 방법
1. `num_list_len`을 이용해 배열의 길이를 확인한다.
2. 배열의 길이가 10보다 크면 `for`문을 이용해 모든 원소를 더한다.
3. 배열의 길이가 10 이하이면 `answer`를 1로 설정한다.
4. `for`문을 이용해 모든 원소를 곱한다.
5. 계산된 `answer`를 반환한다.
