# 🚀 프로그래머스: 특정 형질을 가지는 대장균 찾기 (MySQL)

## 📌 문제 설명

ECOLI_DATA 테이블에서 **2번 형질은 보유하지 않으면서, 1번이나 3번 형질을 보유하고 있는 대장균 개체의 수(`COUNT`)**를 출력하는 SQL문을 작성하는 문제입니다.

- 1번과 3번 형질을 모두 보유하고 있는 경우도 1번이나 3번 형질을 보유한 경우에 포함됩니다.
- 최초의 대장균 개체의 `PARENT_ID`는 NULL 값입니다.

---

## 💡 핵심 아이디어 & 접근법

1. **비트 연산(Bitwise AND, `&`) 활용**
   - 대장균의 형질(`GENOTYPE`)은 정수형으로 저장되어 있지만, 내부적으로는 **이진수 비트(Bit)**로 표현됩니다.
   - 각 형질 번호에 따른 비트 마스크 값:
     - **1번 형질:** `1` ($2^0$)
     - **2번 형질:** `2` ($2^1$)
     - **3번 형질:** `4` ($2^2$) _주의: 3번 형질은 숫자 3이 아니라 4입니다!_
     - **4번 형질:** `8` ($2^3$)

2. **조건식 구성하기**
   - **2번 형질이 없어야 함:** `(GENOTYPE & 2) = 0` (비트 연산 결과가 0)
   - **1번 또는 3번 형질을 보유해야 함:** `(GENOTYPE & 1) > 0 OR (GENOTYPE & 4) > 0`

---

## 💻 정답 SQL 코드

```sql
SELECT COUNT(*) AS COUNT
FROM ECOLI_DATA
WHERE (GENOTYPE & 2) = 0                          -- 2번 형질을 보유하지 않음
  AND ((GENOTYPE & 1) > 0 OR (GENOTYPE & 4) > 0); -- 1번 또는 3번 형질을 보유함
```
