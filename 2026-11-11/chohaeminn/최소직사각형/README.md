# [Programmers] 최소직사각형

## 1. 개요

- **문제 링크**: https://school.programmers.co.kr/learn/courses/30/lessons/86491
- **난이도**: Level 1
- **분류 (자료구조/알고리즘)**: 완전탐색 (Brute Force), 그리디 (Greedy), 2차원 배열 (2D Array)

---

## 2. 문제 설명

명함 지갑을 만드는 회사에서 다양한 모양과 크기의 명함들을 모두 수납할 수 있으면서 가장 작은 지갑을 만들고자 한다. 명함은 **90도 회전시켜 수납**할 수 있다.

모든 명함의 가로(`w`), 세로(`h`) 길이를 담은 2차원 배열 `sizes`가 주어질 때, 모든 명함을 수납할 수 있는 최소 지갑의 크기(`가로 x 세로`)를 반환하는 `solution` 함수를 작성해야 한다.

---

## 3. 사용 자료구조 & 접근 방식

### 1) 사용 자료구조

- **2차원 배열 (`list[list[int]]`)**: 입력값으로 주어진 명함의 가로/세로 수치 데이터 `sizes`
- **단순 변수 (`int`)**: 최댓값 추적용 변수 `max_w`, `min_h` (추가 메모리 없이 $O(1)$ 공간 복잡도 유지)

### 2) 접근 아이디어

1. **변의 역할 재정의 (회전 성질 활용)**
   - 명함을 회전할 수 있으므로 '가로'와 '세로'라는 고정 명칭 대신 각 명함의 **'긴 변'**과 **'짧은 변'**으로 기준을 통일한다.
2. **방향 통일**
   - 각 명함 `[w, h]`에 대해 `max(w, h)`는 긴 변으로, `min(w, h)`는 짧은 변으로 분류한다.
3. **최대 범위 계산**
   - 모든 명함을 수납하려면:
     - **지갑의 가로 (긴 변 축)** $\ge$ 명함들의 긴 변 중 최댓값
     - **지갑의 세로 (짧은 변 축)** $\ge$ 명함들의 짧은 변 중 최댓값
   - 따라서 `(긴 변 중 최댓값) × (짧은 변 중 최댓값)`이 최소 지갑 크기가 된다.

---

## 4. 코드 (Python)

```python
def solution(sizes):
    max_w = 0  # 긴 변들 중 최댓값
    min_h = 0  # 짧은 변들 중 최댓값

    for w, h in sizes:
        w_values = max(w, h)  # 이번 명함의 긴 변
        h_values = min(w, h)  # 이번 명함의 짧은 변

        max_w = max(max_w, w_values)
        min_h = max(min_h, h_values)

    return max_w * min_h
```
