# 다음에 올 숫자

## 1. 문제 설명

등차수열 또는 등비수열 `common`이 주어질 때, 마지막 원소 다음에 올 숫자를 반환하는 문제이다.

- **등차수열**: 연속된 두 원소의 차이가 일정한 수열
- **등비수열**: 연속된 두 원소의 비율이 일정한 수열

### 입출력 예시

| common | result |
|---|---|
| [1, 2, 3, 4] | 5 |
| [2, 4, 8] | 16 |

## 2. 풀이 아이디어

처음 세 원소를 이용하여 등차수열인지 등비수열인지 판단하였다.

1. 첫 번째와 두 번째 원소의 차이 `d`를 구한다.
2. 두 번째와 세 번째 원소의 차이 `l`을 구한다.
3. `d == l`이면 등차수열이므로 마지막 원소에 공차를 더한다.
4. 그렇지 않으면 등비수열이므로 공비를 구한 뒤 마지막 원소에 곱한다.

## 3. 풀이 과정

**① 등차수열과 등비수열 구분**

처음 세 원소의 연속된 차이를 비교한다. 두 차이가 같으면 등차수열, 다르면 등비수열로 판단한다.

**② 등차수열인 경우**

마지막 원소에 첫 번째와 두 번째 원소의 차이인 공차 `d`를 더하여 정답을 구한다.

**③ 등비수열인 경우**

두 번째 원소를 첫 번째 원소로 나누어 공비 `r`을 구하고, 마지막 원소에 곱하여 정답을 구한다.

## 4. 핵심 개념

- **배열 인덱스**: 배열의 원소에 접근할 때 0부터 시작하는 인덱스를 사용한다.
- **배열의 마지막 원소**: 배열 길이에서 1을 뺀 인덱스로 접근한다.
- **조건문**: `if-else`를 이용하여 수열의 종류에 따라 다른 연산을 수행한다.
- **정수 나눗셈**: 등비수열의 공비를 계산할 때 나눗셈 연산을 사용한다.

## 5. 시간 복잡도

- **시간 복잡도: O(1)** — 배열의 길이와 관계없이 일정한 횟수의 연산만 수행한다.
- **공간 복잡도: O(1)** — 추가 변수만 사용하므로 일정한 공간이 필요하다.

## 6. 개선할 점

- 사용하지 않는 변수는 제거하여 코드를 간결하게 작성할 수 있다.
- 동일한 값을 저장하는 변수를 중복 선언하지 않고 재사용할 수 있다.
- 공비를 계산할 때 0으로 나누는 경우가 발생하지 않도록 입력 조건을 고려해야 한다.
