# [프로그래머스] 가장 큰 수 - Python3

## 📌 문제 설명

0 또는 양의 정수가 주어졌을 때, 정수를 이어 붙여 만들 수 있는 가장 큰 수를 알아내 주세요.

예를 들어, 주어진 정수가 `[6, 10, 2]`라면 `[6102, 6210, 1062, 1026, 2610, 2106]`를 만들 수 있고, 이 중 가장 큰 수는 `6210`입니다.

0 또는 양의 정수가 담긴 배열 `numbers`가 매개변수로 주어질 때, 순서를 재배치하여 만들 수 있는 가장 큰 수를 문자열로 바꾸어 return 하도록 `solution` 함수를 작성해 주세요.

### 제한 사항

- `numbers`의 길이는 1 이상 100,000 이하입니다.
- `numbers`의 원소는 0 이상 1,000 이하입니다.
- 정답이 너무 클 수 있으니 문자열로 바꾸어 return 합니다.

### 입출력 예

| numbers             | return      |
| :------------------ | :---------- |
| `[6, 10, 2]`        | `"6210"`    |
| `[3, 30, 34, 5, 9]` | `"9534330"` |

---

## 💡 풀이 핵심 아이디어

이 문제는 정수 자체의 크기가 아니라 **"두 수를 이어 붙였을 때 어떤 순서가 더 큰 결과를 만드는가"**를 기준으로 정렬해야 합니다.

1. **문자열 변환:**  
   수치적 정렬이 아닌 문자열 사전순 정렬을 이용해야 하므로 `map(str, numbers)`를 통해 문자열 리스트로 변환합니다.

2. **`x * 3`을 활용한 정렬 기준 생성:**
   - 원소가 **최대 1,000 이하**이므로 문자열을 3번 반복하면 자릿수가 달라도 사전순 비교가 가능해집니다.
   - 예: `'3'`과 `'30'` 비교시 $\rightarrow$ `'333'` vs `'303030'` 사전순 비교 시 `'333'`이 더 큼 $\rightarrow$ `'3'`이 앞에 배치됨 (`330` > `303`).
   - 예: `'34'`와 `'3'` 비교시 $\rightarrow$ `'343434'` vs `'333'` 사전순 비교 시 `'343434'`가 더 큼 $\rightarrow$ `'34'`가 앞에 배치됨 (`343` > `334`).

3. **`[0, 0, 0]` 예외 처리:**
   - 입력 데이터가 모두 `0`으로 구성된 경우 결합 결과가 `"000"`이 됩니다.
   - 올바른 반환값은 `"0"`이어야 하므로, 내림차순 정렬 후 첫 번째 글자(`answer[0]`)가 `'0'`인 경우 `"0"`을 반환하도록 처리합니다.

---

## 💻 정답 코드 (`solution.py`)

```python
def solution(numbers):
    # 1. 모든 정수를 문자열로 변환
    numbers = list(map(str, numbers))

    # 2. x * 3 기준으로 내림차순 정렬
    numbers.sort(key=lambda x: x * 3, reverse=True)

    # 3. 정렬된 문자열들을 하나로 연결
    answer = ''.join(numbers)

    # 4. '000' 형태의 예외 처리 후 반환
    return '0' if answer[0] == '0' else answer
```
