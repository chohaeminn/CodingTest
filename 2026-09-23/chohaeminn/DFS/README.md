# 단지번호붙이기

- 문제 링크: https://www.acmicpc.net/problem/2667
- 분류: DFS

## 문제 설명

지도에서 서로 연결된 집을 하나의 단지로 묶습니다.  
단지의 개수와 각 단지에 속한 집의 수를 오름차순으로 출력하는 문제입니다.

## 풀이 설명

지도의 모든 칸을 순회합니다.

아직 방문하지 않은 집을 발견하면 DFS를 실행하여 연결된 집을 모두 방문하고,
해당 단지에 속한 집의 개수를 계산합니다.

각 단지의 크기를 리스트에 저장한 뒤 오름차순으로 정렬하여 출력합니다.

## 시간 복잡도

모든 칸을 한 번씩 방문하므로 시간 복잡도는 `O(N²)`입니다.
