# 서울에 위치한 식당 목록 출력하기

- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/131118
- 분류: `JOIN`, `GROUP BY`

## 문제 설명

`REST_INFO` 테이블과 `REST_REVIEW` 테이블에서 서울에 위치한 식당의 정보를 조회하는 문제입니다.

다음 항목을 출력합니다.

- 식당 ID
- 식당 이름
- 음식 종류
- 즐겨찾기 수
- 주소
- 리뷰 평균 점수

리뷰 평균 점수는 소수점 셋째 자리에서 반올림하여 소수점 둘째 자리까지 표시합니다.

## 풀이 설명

1. `REST_INFO`와 `REST_REVIEW`를 식당 ID인 `REST_ID`를 기준으로 조인합니다.
2. `ADDRESS LIKE '서울%'` 조건을 사용하여 서울에 위치한 식당만 조회합니다.
3. 식당별 리뷰 평균 점수를 구하기 위해 식당 정보로 그룹화하고 `AVG(REVIEW_SCORE)`를 사용합니다.
4. `ROUND(..., 2)`를 사용하여 평균 점수를 소수점 둘째 자리까지 반올림합니다.
5. 평균 점수를 기준으로 내림차순 정렬하고, 평균 점수가 같으면 즐겨찾기 수를 기준으로 내림차순 정렬합니다.
