# 조건에 부합하는 중고거래 댓글 조회하기

- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/164673
- 분류: `JOIN`, `WHERE`, `ORDER BY`

## 문제 설명

`USED_GOODS_BOARD`와 `USED_GOODS_REPLY` 테이블에서 **2022년 10월에 작성된 게시글**에 달린 댓글을 조회하는 문제입니다.

다음 항목을 출력합니다.

- 게시글 제목
- 게시글 ID
- 댓글 ID
- 댓글 작성자 ID
- 댓글 내용
- 댓글 작성일

결과는 댓글 작성일을 기준으로 오름차순 정렬하고, 댓글 작성일이 같으면 게시글 제목을 기준으로 오름차순 정렬합니다.

## 풀이 설명

1. 두 테이블을 게시글 ID인 `BOARD_ID`를 기준으로 조인합니다.
2. `B.CREATED_DATE LIKE '2022-10%'` 조건으로 2022년 10월에 작성된 게시글만 조회합니다.
3. `R.CREATED_DATE ASC`로 댓글 작성일이 빠른 순서대로 정렬합니다.
4. 댓글 작성일이 같을 경우 `B.TITLE ASC`로 게시글 제목을 오름차순 정렬합니다.

## 주의사항

필터링 대상은 댓글 작성일이 아닌 **게시글 작성일**입니다. 또한 `CREATED_DATE`는 문제에서 요구하는 날짜 형식과 일치해야 합니다.
