# 프로그래머스 - 타겟 넘버

## 문제 설명

정수 배열 `numbers`가 주어졌을 때, 각 숫자 앞에 `+` 또는 `-`를 붙여 계산합니다.
모든 숫자를 사용해 `target`을 만드는 방법의 수를 구하는 문제입니다.

예를 들어 `numbers`가 `[1, 1, 1, 1, 1]`이고 `target`이 `3`이라면,
목표값을 만드는 방법은 다음과 같이 5개입니다.

```text
-1 + 1 + 1 + 1 + 1 = 3
+1 - 1 + 1 + 1 + 1 = 3
+1 + 1 - 1 + 1 + 1 = 3
+1 + 1 + 1 - 1 + 1 = 3
+1 + 1 + 1 + 1 - 1 = 3
```

## 입력 형식

이 저장소의 `solution.py`는 로컬 실행을 위해 다음과 같이 입력받습니다.

```text
[숫자1,숫자2,...]
target
```

입력 예시:

```text
[1,1,1,1,1]
3
```

## 출력 예시

```text
5
```

## 풀이 방법

DFS(깊이 우선 탐색)를 사용해 각 숫자를 더하는 경우와 빼는 경우를 모두 탐색합니다.

1. `idx`는 현재 사용할 숫자의 위치를 나타냅니다.
2. `current_sum`은 지금까지 계산한 합을 나타냅니다.
3. 현재 숫자를 더하는 경우와 빼는 경우로 나누어 재귀 호출합니다.
4. 모든 숫자를 사용했을 때 합이 `target`과 같으면 `1`, 다르면 `0`을 반환합니다.
5. 각 경우에서 반환된 값을 모두 더해 정답을 구합니다.

```python
plus = dfs(idx + 1, current_sum + numbers[idx])
minus = dfs(idx + 1, current_sum - numbers[idx])

return plus + minus
```

## 복잡도

- 시간 복잡도: `O(2^N)`
- 공간 복잡도: `O(N)`

각 숫자마다 `+`와 `-` 두 가지 선택지가 있어 총 `2^N`개의 경우를 확인합니다.
재귀 호출의 최대 깊이는 숫자의 개수인 `N`입니다.
