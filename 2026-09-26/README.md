# 🎯 프로그래머스 - 타겟 넘버 (DFS)

---

## 📌 문제 개요

- **출처:** 프로그래머스 코딩테스트 연습 (DFS/BFS)
- **목적:** 주어진 정수 배열의 숫자를 순서를 바꾸지 않고 적절히 더하거나 빼서 타겟 넘버(`target`)를 만드는 방법의 수 구하기
- **제한사항:** 숫자의 개수 2~20개, 각 숫자 1~50, 타겟 넘버 1~1000

---

## 💡 1. 푸는 방법 (Solution Approach)

이 문제는 모든 숫자에 대해 **더하기(`+`)**와 **빼기(`-`)**의 모든 경우의 수를 확인해야 하는 **완전탐색(DFS)** 문제입니다.

1. **재귀 함수 설계:** 현재 탐색 중인 인덱스(`index`)와 지금까지 계산된 누적 합(`current_sum`)을 상태값으로 전달하며 재귀를 호출합니다.
2. **분기 처리 (가지치기):** 각 단계마다 다음 숫자를 **더하는 경우**와 **빼는 경우** 두 갈래로 나누어 트리를 탐색합니다.
3. **종료 조건 및 카운팅:** 배열의 모든 숫자를 다 사용했을 때(`index == len(numbers)`), 누적된 합이 타겟 넘버와 일치하면 성공을 의미하는 `1`을 리턴하고, 틀렸다면 `0`을 리턴합니다.
4. **결과 합산:** 양쪽 갈래(더하기, 빼기)에서 리턴된 값들을 `plus + minus` 형태로 더해주어 최종 최상단까지 방법의 개수를 모아줍니다.

---

## ⏱️ 2. 시간 복잡도 (Time Complexity)

- **$O(2^N)$** (단, $N$은 `numbers` 배열의 길이)
- 배열의 각 숫자마다 `+` 또는 `-`를 선택하는 2가지 경우의 수가 존재합니다.
- 문제가 제한하는 숫자의 최대 개수는 20개이므로, 최대 $2^{20}$ (약 100만 번)의 연산이 발생합니다. 컴퓨터가 1초 내에 처리할 수 있는 연산 횟수(약 1억 번)에 비해 훨씬 적으므로 시간 내에 안전하게 통과할 수 있습니다.

---

## 📦 3. 자료구조 (Data Structures)

- **배열 (Array / List):**
  - 입력으로 주어지는 정수 모음인 `numbers`를 저장하고 순차적으로 접근하기 위해 사용합니다.
- **재귀 호출 스택 (Recursion Call Stack):**
  - DFS 탐색을 구현할 때 함수가 자기 자신을 호출하면서 생기는 실행 컨텍스트를 메모리에 쌓아두는 시스템 스택입니다.
  - 이를 통해 각 단계에서의 `index`와 현재까지의 합(`current_sum`) 상태를 안전하게 기억하고 이전 단계로 돌아갈 수 있습니다.
