# 과일 장수

## 문제
프로그래머스 - 과일 장수

사과의 점수가 담긴 배열 `score`와 한 상자에 담을 사과의 개수 `m`이 주어진다.

한 상자의 가격은 **상자에 담긴 사과 중 최저 점수 × 사과 개수(m)** 로 결정된다.

사과를 상자에 담아 판매할 때 얻을 수 있는 최대 이익을 구하는 문제이다.

## 풀이 방법

### 1. 사과 점수 내림차순 정렬
- 점수가 높은 사과부터 상자에 담아야 최대 이익을 얻을 수 있다.
- 이중 `for`문을 이용한 **버블 정렬**로 배열을 내림차순 정렬했다.
- 앞의 점수가 뒤의 점수보다 작으면 `temp` 변수를 이용해 두 값을 교환했다.

### 2. 판매 가능한 상자 개수 계산
```c
int box = score_len / m;
int sell = box * m;
```
- `box`: 만들 수 있는 상자의 개수
- `sell`: 실제로 판매할 수 있는 사과의 개수
- 상자에 담지 못하는 나머지 사과는 제외했다.

### 3. 최대 이익 계산
```c
for(int i = 0; i < sell; i++){
    if((i+1)%m == 0){
        sum += score[i]*m;
    }
}
```
- 정렬된 배열에서 `m`개씩 사과를 묶는다.
- `(i+1)%m == 0`을 이용해 각 상자의 마지막 사과를 찾는다.
- 내림차순이므로 마지막 사과가 해당 상자의 최저 점수이다.
- `score[i] * m`을 총이익에 누적한다.

## 시간 복잡도

- 버블 정렬: `O(n²)`
- 최대 이익 계산: `O(n)`
- 전체 시간 복잡도: **O(n²)**

배열을 내림차순으로 정렬한 뒤 각 상자의 최저 점수만 선택하여 최대 이익을 계산했다.

다만 버블 정렬을 사용했기 때문에 입력 크기가 커지면 시간 초과가 발생할 수 있다.
