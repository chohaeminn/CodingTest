# 과일 장수

## 문제
프로그래머스 - 과일 장수

사과의 점수가 담긴 배열 `score`와 한 상자에 담을 사과의 개수 `m`이 주어진다.

한 상자의 가격은 **상자에 담긴 사과 중 최저 점수 × 사과 개수(m)** 로 결정된다.

사과를 상자에 담아 판매할 때 얻을 수 있는 최대 이익을 구하는 문제이다.

## 풀이 방법

### 1. 사과 점수 내림차순 정렬
- 점수가 높은 사과부터 상자에 담아야 최대 이익을 얻을 수 있다.
- 기존 버블 정렬은 시간 초과가 발생하여 `qsort()` 함수로 변경했다.
- `compare()` 비교 함수를 이용해 사과 점수를 내림차순으로 정렬했다.

### 2. 판매 가능한 상자 개수 계산

```c
int box = score_len / m;
int sell = box * m;
```

- `box`: 만들 수 있는 상자의 개수
- `sell`: 실제로 판매할 수 있는 사과의 개수
- 상자에 담지 못하는 나머지 사과는 제외했다.

### 3. 최대 이익 계산

```c
for(int i = 0; i < sell; i++){
    if((i+1)%m == 0){
        sum += score[i]*m;
    }
}
```

- 정렬된 배열에서 `m`개씩 사과를 묶는다.
- `(i+1)%m == 0`을 이용해 각 상자의 마지막 사과를 찾는다.
- 내림차순이므로 마지막 사과가 해당 상자의 최저 점수이다.
- `score[i] * m`을 총이익에 누적한다.

## 시간 복잡도

- `qsort()` 정렬: 평균 `O(n log n)`
- 최대 이익 계산: `O(n)`
- 전체 평균 시간 복잡도: **O(n log n)**

처음에는 버블 정렬을 이용했지만 입력 데이터가 많아지면서 시간 초과가 발생했다. 이를 해결하기 위해 `qsort()`를 사용하여 정렬 성능을 개선했다.

정렬 이후에는 각 상자의 최저 점수만 선택하여 최대 이익을 계산하도록 구현했다.
