# 분수의 덧셈

## 문제 링크
https://school.programmers.co.kr/learn/courses/30/lessons/120808

## 문제 설명
첫 번째 분수의 분자와 분모를 numer1, denom1,
두 번째 분수의 분자와 분모를 numer2, denom2라고 할 때,
두 분수를 더한 값을 기약 분수로 나타냈을 때
분자와 분모를 순서대로 담은 배열을 반환합니다.

## 풀이 설명
1. 두 분모의 최소공배수를 구한다.
2. 최소공배수를 공통 분모로 하여 각 분자를 변환한다.
3. 변환한 두 분자를 더한다.
4. 분자와 분모의 최대공약수를 구한다.
5. 분자와 분모를 최대공약수로 나누어 기약분수로 만든다.
