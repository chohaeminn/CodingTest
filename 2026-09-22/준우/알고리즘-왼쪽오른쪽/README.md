# 왼쪽 오른쪽

## 문제 링크
https://school.programmers.co.kr/learn/courses/30/lessons/181890

## 문제 설명
문자열 배열 str_list에서 "l"과 "r" 중 먼저 나오는 문자열을 기준으로 배열을 나눕니다.

"l"이 먼저 나오면 해당 문자열의 왼쪽에 있는 문자열들을 반환하고,
"r"이 먼저 나오면 해당 문자열의 오른쪽에 있는 문자열들을 반환합니다.

"l"과 "r"이 모두 없다면 빈 배열을 반환합니다.

## 풀이 설명
1. str_list를 처음부터 순회하며 "l" 또는 "r"이 처음 등장하는 위치를 찾는다.
2. "l"을 발견하면 해당 위치 이전의 문자열들을 새로운 배열에 복사한다.
3. "r"을 발견하면 해당 위치 이후의 문자열들을 새로운 배열에 복사한다.
4. "l"과 "r"이 모두 존재하지 않으면 빈 배열을 반환한다.
5. 반환할 문자열 배열과 각 문자열의 공간은 malloc을 이용해 동적 할당한다.
