# 그림

## 문제 링크

https://www.acmicpc.net/problem/1926

## 문제 설명

어떤 도화지에 그림이 그려져 있을 때 그 그림의 개수와, 그 그림 중 넓이가 가장 넓은 것의 넓이를 출력한다.

- 그림이란 1로 연결된 것을 한 그림이라고 정의한다.
- 가로나 세로로 연결된 것은 연결된 것이고, 대각선으로 연결된 것은 떨어진 그림이다.
- 그림의 넓이란 그림에 포함된 1의 개수이다.

**입력**

- 첫째 줄에 도화지의 세로 크기 N과 가로 크기 M이 주어진다. (1 ≤ N, M ≤ 500)
- 둘째 줄부터 N개의 줄에 그림의 정보가 0과 1로 공백을 두고 주어진다. (0은 색칠 안 된 부분, 1은 색칠된 부분)

**출력**

- 첫째 줄에 그림의 개수, 둘째 줄에 그 중 가장 넓은 그림의 넓이를 출력한다.
- 그림이 하나도 없는 경우 가장 넓은 그림의 넓이는 0이다.

## 풀이

전체 격자를 순회하면서 아직 방문하지 않은 1을 발견할 때마다 BFS로 상하좌우로 연결된 칸을 모두 탐색해 하나의 그림으로 묶는다.

- 그림 개수: BFS를 새로 시작할 때마다 1씩 증가
- 그림 넓이: BFS로 방문한 칸의 개수
- 방문 배열(`chk`)로 같은 칸을 중복 탐색하지 않도록 하여, 서로 다른 그림끼리 겹치지 않게 함

**시간복잡도**: O(N × M) — 각 칸을 한 번씩만 방문하고 4방향만 확인하므로 500×500 크기에서도 충분히 빠르다.
