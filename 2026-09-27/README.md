# 홀수 vs 짝수

## 문제 링크

https://school.programmers.co.kr/learn/courses/30/lessons/181887

## 문제 설명

정수 리스트 `num_list`가 주어집니다. 가장 첫 번째 원소를 1번 원소라고 할 때, 홀수 번째 원소들의 합과 짝수 번째 원소들의 합 중 큰 값을 return 하도록 solution 함수를 완성해주세요.

## 풀이 설명

1. 홀수 번째 원소의 합과 짝수 번째 원소의 합을 저장할 변수를 각각 만든다.
2. 인덱스 0부터 시작하여 2씩 증가시키면서 해당 위치의 원소를 더한다.
3. 인덱스 1부터 시작하여 2씩 증가시키면서 해당 위치의 원소를 더한다.
4. 두 합을 비교한다.
5. 두 값 중 더 큰 값을 반환한다.
