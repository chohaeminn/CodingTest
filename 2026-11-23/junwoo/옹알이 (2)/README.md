
# 옹알이 (2)

- 플랫폼: 프로그래머스
- 난이도: Level 1
- 언어: C
- 날짜: 2026-11-23

## 문제 설명

문자열 배열 babbling이 주어졌을 때,
"aya", "ye", "woo", "ma" 네 가지 발음과
이들의 조합으로 만들 수 있는 단어의 개수를 반환한다.

단, 같은 발음을 연속해서 사용할 수 없다.

## 풀이 방법

1. for문으로 babbling 배열의 문자열을 하나씩 검사한다.
2. while문을 사용하여 문자열의 처음부터 끝까지 순회한다.
3. strncmp()를 이용해 현재 위치에서 네 가지 발음을 비교한다.
4. 일치하는 발음이 발견되면 j를 해당 발음의 길이만큼 증가시킨다.
5. prev 변수로 직전에 사용한 발음을 기억하여 같은 발음이 연속되는 것을 방지한다.
6. 올바르지 않은 발음이 발견되면 valid 값을 변경하고 반복문을 종료한다.
7. 문자열 전체가 올바른 발음으로 구성되어 있으면 answer를 증가시킨다.

## 사용 개념

- for문과 while문
- 문자열 비교 함수 strncmp()
- 문자열 길이 함수 strlen()
- 문자열 인덱스 이동
- 이전 상태 저장을 통한 연속 중복 검사
- break를 이용한 반복문 종료

## 시간 복잡도

O(N × L)

N: babbling 배열의 길이
L: 문자열 하나의 최대 길이

각 문자열을 앞에서부터 검사하며,
발음 비교는 최대 3글자씩 수행한다.
