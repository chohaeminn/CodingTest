# 배열에서 문자열 대소문자 변환하기

## 문제 설명

문자열 배열 `strArr`가 주어집니다.

모든 원소가 알파벳으로만 이루어져 있을 때,  
배열에서 홀수 번째 인덱스의 문자열은 모든 문자를 대문자로,  
짝수 번째 인덱스의 문자열은 모든 문자를 소문자로 바꾸어 반환합니다.

## 제한사항

- `1 ≤ strArr`의 길이 `≤ 20`
- `1 ≤ strArr`의 원소의 길이 `≤ 20`
- `strArr`의 원소는 알파벳으로 이루어진 문자열입니다.

## 풀이

문자열 배열을 순회하면서 인덱스가 짝수인지 홀수인지 확인합니다.

- 짝수 인덱스: `tolower()`를 사용하여 소문자로 변환
- 홀수 인덱스: `toupper()`를 사용하여 대문자로 변환

각 문자열의 길이만큼 동적 메모리를 할당하고,
마지막에 널 문자 `'\0'`을 추가하여 문자열을 완성합니다.
