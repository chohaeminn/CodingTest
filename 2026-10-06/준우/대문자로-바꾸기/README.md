# 대문자로 바꾸기

## 문제 설명

알파벳으로 이루어진 문자열 `myString`이 주어집니다.  
모든 알파벳을 대문자로 변환하여 반환하는 함수를 완성하세요.

## 제한사항

- `1 ≤ myString`의 길이 `≤ 100,000`
- `myString`은 알파벳으로 이루어진 문자열입니다.

## 입출력 예

| myString | result |
|---|---|
| `"aBcDeFg"` | `"ABCDEFG"` |
| `"AAA"` | `"AAA"` |

## 풀이

문자열을 처음부터 끝까지 순회하면서 각 문자를 `toupper()` 함수를 이용해 대문자로 변환합니다.

변환한 문자를 동적으로 할당한 문자열에 저장하고, 마지막에 널 문자 `'\0'`을 추가하여 문자열을 완성합니다.
