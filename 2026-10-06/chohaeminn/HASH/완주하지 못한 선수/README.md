# [프로그래머스] 완주하지 못한 선수 (Python)

### 문제 설명

마라톤에 참여한 선수들의 이름이 담긴 배열 participant와 완주한 선수들의 이름이 담긴 배열 completion이 주어질 때, 완주하지 못한 선수의 이름을 구하는 문제입니다. (단, 동명이인이 있을 수 있습니다.)

---

### 왜 해시(Hash)를 사용하는가?

- 마라톤에 참여한 선수의 수는 최대 100,000명에 이를 수 있습니다.
- 만약 단순 반복문을 사용해 일일이 비교한다면 O(N^2)의 시간 복잡도가 소요되어 시간 초과가 발생합니다.
- 해시 구조와 딕셔너리를 활용하면 데이터 검색 및 저장을 평균 O(1)의 시간 복잡도로 처리할 수 있어, 전체 알고리즘의 성능을 O(N)으로 효율적으로 최적화할 수 있습니다.

---

### 사용한 주요 함수

- `hash(object)`: 파이썬 내장 함수로, 문자열 등의 객체를 고유한 정수 값(해시 값)으로 변환합니다.
- `딕셔너리 (Dictionary)`: 해시 값을 키로, 선수의 이름을 값으로 저장하여 최종 남은 해시 값으로 원래의 이름을 바로 찾아낼 수 있도록 합니다.

---

### 시간 복잡도

- **전체 시간 복잡도**: O(N) (여기서 N은 참가자 배열의 길이)
  - 참가자 배열을 순회하며 해시 값을 구하고 총합에 더하는 연산: O(N)
  - 완주자 배열을 순회하며 해시 값을 총합에서 빼기: O(N)
  - 딕셔너리에서 키를 통해 값을 조회하는 연산: O(1)

---

### 소스 코드 (`solution.py`)

```python
def solution(participant, completion):
    hash_dict = {}
    sum_hash = 0

    # 참가자들의 이름을 해시 값으로 변환하여 모두 더하고, 딕셔너리에 저장
    for part in participant:
        hash_val = hash(part)
        hash_dict[hash_val] = part
        sum_hash += hash_val

    # 완주자들의 해시 값을 총합에서 빼기
    for comp in completion:
        sum_hash -= hash(comp)

    # 남은 해시 값(완주하지 못한 선수)에 해당하는 이름 반환
    return hash_dict[sum_hash]
```
