# 프로그래머스 - 카펫 (Python)

## 1. 문제 요약

- 중앙은 노란색(`yellow`), 가장자리 1줄은 갈색(`brown`)으로 칠해진 직사각형 카펫의 격자 수가 주어질 때, 전체 카펫의 `[가로, 세로]` 크기를 구하는 문제입니다.
- 제한사항: 가로 길이는 세로 길이와 같거나 깁니다 ($w \ge h$).

## 2. 접근 방법 및 알고리즘

- **알고리즘:** 완전탐색 (Brute-Force)
- **사용 자료구조:** 없음 (단순 정수형 변수 및 반환용 리스트 사용, 공간 복잡도 $O(1)$)
- **풀이 원리:**
  1. 전체 카펫의 넓이는 `total = brown + yellow`입니다.
  2. 테두리 1줄이 갈색이므로 노란색 영역의 가로는 `w - 2`, 세로는 `h - 2`가 됩니다.
  3. 전체 넓이(`total`)의 약수 쌍 `(w, h)`를 탐색하면서 `(w - 2) * (h - 2) == yellow` 조건을 만족하는 경우를 찾습니다.
  4. 노란색 격자가 최소 1개 이상이므로 세로(`h`)는 최소 `3` 이상이며, 가로가 세로보다 크거나 같으므로($w \ge h$) 세로(`h`)는 $\sqrt{\text{total}}$까지만 탐색합니다.

## 3. 코드 구현

```python
def solution(brown, yellow):
    total = brown + yellow

    for h in range(3, int(total ** 0.5) + 1):
        if total % h == 0:
            w = total // h
            if (w - 2) * (h - 2) == yellow:
                return [w, h]
```
