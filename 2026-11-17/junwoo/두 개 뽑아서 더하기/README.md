
# 두 개 뽑아서 더하기

- 플랫폼: 프로그래머스
- 언어: C
- 날짜: 2026-11-17

## 문제 설명
정수 배열 numbers에서 서로 다른 인덱스에 있는 두 수를 뽑아 더한다.
나올 수 있는 모든 합을 중복 없이 오름차순으로 정렬하여 반환한다.

## 풀이 방법
1. 이중 for문으로 서로 다른 두 원소를 선택한다.
2. 선택한 두 원소의 합을 계산한다.
3. 결과 배열에 동일한 값이 있는지 확인한다.
4. 중복이 없으면 결과 배열에 추가한다.
5. qsort()를 이용해 오름차순으로 정렬한다.

## 사용 개념
- 이중 반복문
- 동적 메모리 할당 malloc()
- 배열 중복 검사
- qsort() 정렬
