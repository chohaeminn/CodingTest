# 수열과 구간 쿼리 1

## 문제
정수 배열 `arr`와 2차원 정수 배열 `queries`가 주어진다.

각 `query`는 `[s, e]` 형태이며,  
`s ≤ i ≤ e`인 모든 인덱스 `i`에 대해 `arr[i]`에 1을 더한다.

모든 쿼리를 순서대로 처리한 후의 `arr`을 반환한다.

## 풀이
1. `queries`를 처음부터 하나씩 확인한다.
2. 각 쿼리의 시작 인덱스와 끝 인덱스 범위를 확인한다.
3. 해당 범위에 포함되는 `arr[k]`의 값을 1 증가시킨다.
4. 모든 쿼리를 처리한 뒤 결과를 `answer`에 저장하여 반환한다.

## 핵심
`queries[i][0]`과 `queries[i][1]`은 배열의 값이 아니라 **인덱스의 범위**를 의미한다.

따라서 `arr[k]`의 값을 범위와 비교하는 것이 아니라 인덱스 `k`가 범위에 포함되는지 확인해야 한다.
