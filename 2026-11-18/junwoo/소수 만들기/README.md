# 소수 만들기

- 플랫폼: 프로그래머스
- 난이도: Level 1
- 언어: C
- 풀이 날짜: 2026-11-18

## 문제 설명

주어진 정수 배열 nums에서 서로 다른 3개의 숫자를 선택하여 더했을 때, 그 합이 소수가 되는 경우의 수를 구하는 문제입니다.

## 풀이 방법

1. 3중 for문을 사용하여 서로 다른 숫자 3개를 선택합니다.
2. 선택한 숫자 3개의 합을 구합니다.
3. 2부터 합보다 작은 수까지 나누어 소수인지 판별합니다.
4. 소수라면 answer를 1 증가시킵니다.
5. 모든 조합을 확인한 후 answer를 반환합니다.

## 시간 복잡도

- 숫자 3개 선택: O(N³)
- 소수 판별: O(S)
- 전체 시간 복잡도: O(N³ × S)

N은 배열의 길이, S는 선택한 세 숫자의 합입니다.

## 핵심 개념

- 3중 반복문을 활용한 조합 탐색
- 나머지 연산자를 활용한 소수 판별
- break를 이용한 불필요한 반복 종료
