# 공백으로 구분하기 1

## 문제 설명
단어가 공백 한 개로 구분되어 있는 문자열 `my_string`이 매개변수로 주어집니다.

`my_string`에 나오는 단어를 앞에서부터 순서대로 담은 문자열 배열을 반환하는 `solution` 함수를 작성하는 문제입니다.

## 제한사항
- `1 ≤ my_string`의 길이 `≤ 1,000`
- `my_string`은 영소문자와 공백으로만 이루어져 있습니다.
- `my_string`의 맨 앞과 맨 뒤에는 공백이 없습니다.

## 입출력 예

| my_string | result |
|---|---|
| "i love you" | ["i", "love", "you"] |
| "programmers" | ["programmers"] |

## 풀이 방법
1. `strlen()`을 사용하여 문자열의 길이를 구합니다.
2. 문자열을 순회하면서 `isspace()`로 공백의 개수를 세어 단어의 개수를 구합니다.
3. `malloc()`을 사용하여 단어 개수만큼 문자열 포인터 배열을 동적 할당합니다.
4. 원본 문자열은 `const char*`이므로 별도의 `temp` 배열에 복사합니다.
5. `strtok()`을 사용하여 공백을 기준으로 문자열을 분리합니다.
6. 각 단어의 길이에 맞게 메모리를 동적 할당하고 `strcpy()`로 복사합니다.
7. `free()`로 임시 문자열의 메모리를 해제한
