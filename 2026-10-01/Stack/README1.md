# [프로그래머스] 올바른 괄호 (Python)

## 📌 문제 설명

괄호가 바르게 짝지어졌다는 것은 '(' 문자로 열렸으면 반드시 짝지어서 ')' 문자로 닫혀야 한다는 뜻입니다.
'(' 또는 ')' 로만 이루어진 문자열 s가 주어졌을 때, 문자열 s가 올바른 괄호이면 `true`를 return 하고, 올바르지 않은 괄호이면 `false`를 return 하는 solution 함수를 완성해 주세요.

- **제한사항**: 문자열 s의 길이 100,000 이하의 자연수 (`'('`, `')'`로만 구성)

---

## 💡 아이디어 & 접근 방법

- 괄호의 종류가 두 가지(`(`, `)`)뿐이므로, 리스트 스택 대신 정수형 변수(`balance`)를 활용해 개수를 카운팅하여 효율적으로 해결했습니다.
- `'('`를 만나면 `+1`, `')'`를 만나면 `-1`을 수행합니다.
- 순회 도중 `balance`가 음수가 되면(`')'`가 더 많아지는 경우) 즉시 `False`를 반환합니다.
- 모든 순회가 끝난 후 `balance == 0`이면 `True`, 아니면 `False`를 반환합니다.

---

## 💻 정답 코드

```python
def solution(s):
    balance = 0

    for char in s:
        if char == '(':
            balance += 1
        else:
            balance -= 1

        # 닫는 괄호가 더 많아지는 순간 올바르지 않은 괄호가 됨
        if balance < 0:
            return False

    # 최종적으로 괄호의 균형이 모두 맞으면 True, 아니면 False
    return balance == 0
```
