# 특정한 문자를 대문자로 바꾸기

## 문제 설명

영소문자로 이루어진 문자열 `my_string`과 영소문자 1글자로 이루어진 문자열 `alp`가 주어집니다.

`my_string`에서 `alp`에 해당하는 모든 글자를 대문자로 바꾼 문자열을 반환합니다.

## 제한사항

- `1 ≤ my_string`의 길이 `≤ 1,000`

## 입출력 예

| my_string | alp | result |
|---|---|---|
| `"programmers"` | `"p"` | `"Programmers"` |
| `"lowercase"` | `"x"` | `"lowercase"` |

## 풀이

문자열 `my_string`을 처음부터 끝까지 순회합니다.

- 현재 문자가 `alp[0]`과 같으면 `toupper()`를 이용해 대문자로 변환합니다.
- 같지 않으면 기존 문자를 그대로 저장합니다.
- 마지막에 널 문자 `'\0'`을 추가하여 문자열을 완성합니다.
