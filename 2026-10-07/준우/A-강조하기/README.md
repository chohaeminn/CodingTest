# A 강조하기

## 문제 설명

문자열 `myString`이 주어집니다.

`myString`에서 알파벳 `"a"`가 등장하면 전부 `"A"`로 변환하고,  
`"A"`가 아닌 모든 대문자 알파벳은 소문자로 변환하여 반환합니다.

## 제한사항

- `1 ≤ myString`의 길이 `≤ 20`
- `myString`은 알파벳으로 이루어진 문자열입니다.

## 입출력 예

| myString | result |
|---|---|
| `"abstract algebra"` | `"AbstrAct AlgebrA"` |
| `"PrOgRaMmErS"` | `"progrAmmers"` |

## 풀이

문자열을 처음부터 끝까지 순회합니다.

- 문자가 `'a'`이면 `'A'`로 변환합니다.
- `'a'`가 아닌 문자는 `tolower()`를 이용해 소문자로 변환합니다.
- 변환된 문자를 새로운 문자열에 저장합니다.
- 마지막에 널 문자 `'\0'`을 추가하여 문자열을 완성합니다.
