# 가장 많이 받은 선물

## 문제 정보
- 플랫폼: 프로그래머스
- 난이도: Level 1
- 출제: 2024 KAKAO WINTER INTERNSHIP
- 사용 언어: C

## 풀이 방법

1. `sscanf()`를 사용하여 선물을 준 사람과 받은 사람의 이름을 분리한다.
2. `strcmp()`를 사용하여 각 친구의 인덱스를 찾는다.
3. 2차원 배열에 친구별 선물을 주고받은 횟수를 저장한다.
4. 준 선물의 총합에서 받은 선물의 총합을 빼서 각 친구의 선물 지수를 계산한다.
5. 두 친구가 주고받은 선물 개수를 비교하고, 개수가 같다면 선물 지수를 비교하여 다음 달에 받을 선물 개수를 계산한다.
6. 다음 달에 받을 선물 개수 중 최댓값을 반환한다.

## 핵심 개념

- 2차원 배열을 활용한 데이터 관리
- `sscanf()`를 활용한 문자열 분리
- `strcmp()`를 활용한 문자열 비교
- 내부 반복문을 `i + 1`부터 시작하여 중복 비교 방지

## 시간 복잡도

- 시간 복잡도: O(MN + N²)
- 공간 복잡도: O(N²) 규모의 배열 사용

N은 친구의 수, M은 선물 기록의 수이다. 실제 구현에서는 최대 50명에 맞춘 고정 크기 배열을 사용하였다.
